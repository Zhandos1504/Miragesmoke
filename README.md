# Смоки Mirage: окно и коннектор

Одностраничный фанатский гайд по двум смокам на карте Mirage в CS2 (за террористов): смок на окно и смок на коннектор. Видео-раскидки, тайминги, частые ошибки и поля для личных заметок Рекомендую не включать видео со смоком на коннектор или же можете смотреть без звука.

**Демо: [mirage4w.netlify.app](https://mirage4w.netlify.app/)**

## О проекте

Мид на Mirage решает многие раунды. Два смока закрывают самые опасные линии обзора: окно убирает снайперскую позицию защитника, коннектор закрывает ротацию. Страница объясняет, зачем их учить, когда бросать и где чаще всего ошибаются.

## Что на странице

- **Главный экран**: заголовок «Два смока, которые открывают мид», вступление и фото.
- **Зачем выучить**: три причины (безопасный проход, закрытая ротация, одна позиция — один бросок).
- **Раскидки**: два видео с YouTube (окно и коннектор), подсказки «Позиция», «Прицел», «Бросок» и поле «Мои заметки».
- **Галерея**: восемь карточек (Окно, Коннектор, Джангл, Стэрс, CT-спавн, Палас, Короткий проход, Маркет). Кнопка «Подробнее →» показывает, что закрывает смок, когда его бросать и совет.
- **Когда бросать**: тайминг важнее точности (сразу со спавна, перед выходом на мид, договорённость в команде).
- **Частые ошибки**: другая точка броска, слишком ранний смок, нет договорённости.
- **Подписка**: форма с именем и email.
- **Навигация** по разделам и ссылка «К содержимому» для быстрого перехода к основной части.

## Запуск локально

Сборка не нужна, это статическая страница.

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере. Или запустите локальный сервер из папки проекта:

   ```bash
   python3 -m http.server 8000
   ```

   и откройте http://localhost:8000.

Для видео нужен интернет: они встроены с YouTube.

## Деплой

Страница опубликована на Netlify. Чтобы выложить свою копию, откройте [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите туда папку проекта целиком (`index.html` и папка с изображениями должны лежать рядом). Подойдёт и GitHub Pages.
